# SecOps Weekly Operations & Reporting Agent 🛡️

An autonomous **SecOps Weekly Operations & Reporting Agent** built with the **Google Agent Development Kit (ADK)** and powered by **Google Cloud Vertex AI Gemini models**.

The agent connects directly to live **Google Security Operations (Chronicle SecOps)** and **Google Threat Intelligence (GTI)** Model Context Protocol (MCP) servers hosted on **Google Cloud Run** to synthesize operational performance, calculate resolution metrics (MTTR), audit playbook automation updates, track remediation actions, and generate executive-ready Weekly Operations Reports.

---

## 🎯 Identity & Purpose

The **SecOps Weekly Operations & Reporting Agent** automates SOC performance analysis and executive reporting by:
1. **Aggregating Case & Alert Telemetry:** Pulling closed, investigating, and active cases/alerts across any 7-day reporting window.
2. **Computing Operational Performance:** Calculating Mean Time to Resolve (MTTR) overall and across severity tiers (Critical, High, Medium, Low/Info).
3. **Tracking Automation & Playbooks:** Auditing newly created and modified SOAR playbooks, YARA-L detection rules, and workflow automations.
4. **Quantifying Key Remediations:** Compiling counts for host isolations, IP/domain blocks, credential resets, process terminations, and policy updates.
5. **Enriching Threat Landscape with GTI:** Correlating recurring threats and high-severity incidents with Google Threat Intelligence.
6. **Delivering Strategic Insights:** Formulating data-driven recommendations on detection engineering, alert fatigue reduction, and automation ROI.

## ⚙️ Configuration & Environment Setup

Authentication uses **Google Cloud Vertex AI Application Default Credentials (ADC)** — zero hardcoded API keys or credentials.

### Environment Variables

| Variable | Description | Default |
|---|---|---|
| `GOOGLE_GENAI_USE_VERTEXAI` | Directs `google-genai` to use Vertex AI | `true` |
| `GOOGLE_CLOUD_PROJECT` | GCP Project ID | Active GCP project |
| `GOOGLE_CLOUD_LOCATION` | GCP Region / Location | `us-central1` |
| `SECOPS_AGENT_MODEL` | Vertex AI Gemini model | `gemini-2.5-flash` |
| `SECOPS_URL` / `SECOPS_MCP_URL` | Endpoint URL for Google SecOps MCP | Cloud Run URL |
| `GTI_URL` / `GTI_MCP_URL` | Endpoint URL for Google Threat Intelligence MCP | Cloud Run URL |
| `AGENT_NAME` | Agent identifier name | `reporting_agent` |
| `GOOGLE_CLOUD_AGENT_ENGINE_ENABLE_TELEMETRY` | OpenTelemetry tracing to Cloud Trace | `true` |

## 🚀 Local Execution & CLI Usage

### 1. Show Active Configuration
```bash

```

### 2. Generate Weekly Report
```bash

```

